# Troubleshooting

## Missing tool errors
Install the required Kali package or run the suite in a mode that does not depend on the missing tool.

## Authorization errors
Ensure the `--authorize` flag is passed and the target is within the intended scope.

## AI issues
Confirm that Ollama is running and the endpoint is reachable.

## Report problems
Check file permissions and ensure the `reports/` directory exists.
